# Toonflow REST API Map

- 169 endpoints, auto-registered from `src/routes/**/*.ts` (see `src/core.ts`).
- All endpoints require JWT (`Authorization: Bearer *** from `o_setting.tokenKey`) except `/api/login/login`.
- Response envelope: `{code: 200|400, data, message}` via `src/lib/responseFormat.ts`.
- Validation: zod `validateFields` middleware (400 on failure, Chinese messages).
- Generated by `yarn docs:routes`. Do not edit by hand.

## `/api/agents`

Agent conversation memory management (clear/get memory).

- `GET /api/agents/memory` ← `src/routes/agents/memory.ts`
- `POST /api/agents/memory/clear` ← `src/routes/agents/memory/clear.ts`

## `/api/artStyle`

Art-style presets CRUD + AI style-prompt extraction.

## `/api/assets`

Assets center: CRUD `o_assets`/`o_image`, audio assets, clip upload, material lists, polling.

- `GET /api/assets` ← `src/routes/assets/index.ts`
- `POST /api/assets` ← `src/routes/assets/create.ts`
- `GET /api/assets/:id` ← `src/routes/assets/[id]/get.ts`
- `PUT /api/assets/:id` ← `src/routes/assets/[id]/update.ts`
- `DELETE /api/assets/:id` ← `src/routes/assets/[id]/delete.ts`
- `POST /api/assets/upload/clip` ← `src/routes/assets/upload/clip.ts`
- `GET /api/assets/materials` ← `src/routes/assets/materials.ts`
- `GET /api/assets/polling` ← `src/routes/assets/polling.ts`

## `/api/assets/generate`

Trigger AI generation of asset images (fire-and-forget + task row), prompt polishing, cancel.

## `/api/common`

## `/api/cornerScape`

## `/api/login`

- `POST /api/login/login` ← `src/routes/login/login.ts`
