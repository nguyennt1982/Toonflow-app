# Toonflow REST API Map

- 169 endpoints, auto-registered from `src/routes/**/*.ts` (see `src/core.ts`).
- All endpoints require JWT (`Authorization: Bearer <token>`, from `o_setting.tokenKey`) except `/api/login/login`.
- Response envelope: `{code: 200|400, data, message}` via `src/lib/responseFormat.ts`.
- Validation: zod `validateFields` middleware (400 on failure, Chinese messages).
- Generated by `yarn docs:routes`. Do not edit by hand.
